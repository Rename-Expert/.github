# Rename Expert — batch rename with a preview list

Rename Expert keeps one named board on the desk: the live list, the preview in front of you, and a short note the next operator can read. Extra guesses wait for their own title.

## Session Card

| Slice | What you do in Rename Expert | What remains |
|-------|------------------------|--------------|
| Arrival | Open Rename Expert and name today's rename desk | A titled preview list |
| Focus | Keep only live names on the Rename Expert board | A short rule list |
| Check | Read Rename Expert preview list before a large rename | A confirmed rename desk |
| Handoff | Mark finished names inside Rename Expert | A note for the next operator |
| Hold | Leave the rule title on the Rename Expert list | A named batch of names |

## How Rename Expert Sits

Rename Expert does not replace a one-click guess, the unlabeled name dump, or a rename of files you do not own. It sits beside them as a named rename desk for one job: which file names are live, which batch rules still match the preview list, and what the next operator should read on files you own.

Morning names return to the same Rename Expert rename desk. Extra guesses wait for their own title instead of crowding the live list.

A first visit should be one short preview pass on names you own, then the same Rename Expert rename desk the next day. That is enough to see if the named batch rules hold.

## Traffic Light

| Signal | On the Rename Expert board | What you do |
|--------|----------------------|-------------|
| Green | Named preview list, short live rule list | Continue the same file names |
| Amber | Two jobs mixed on one preview | Split the batch rules before a large change |
| Red | No title, no note, a one-click guess | Stop and name the rename desk first |
| Clear | Handoff written, live names few | Close Rename Expert and leave the rename desk |
| Hold | Preview written, names still open | Finish the named batch rules, then close |

## Open Order

1. Open the last Rename Expert rename desk, not a new empty preview list.
2. Read the batch rules and the last handoff.
3. Finish one visible preview pass inside Rename Expert on files you own.
4. Write what changed, then close with fewer one-click guesses than you found.
5. If the list feels crowded, drop anything that belongs to a different Rename Expert job.
6. Confirm Rename Expert file names still sit on files you own.
7. Leave the rename desk title on the board before you close.

## After a Week

A week in Rename Expert is not a larger pile of one-click guesses. It is the same title, a shorter live rule list, and a note that still makes sense before the next preview. Take finished names off the live set so the next visit starts on the rename desk that is still open.

Other programs stay where they are. Rename Expert only keeps the path back: desk name, file names you own, preview list, handoff.

Leave Rename Expert with a quieter rename desk than the one you opened. The next visit should start on that named preview list, not on a guess.

## Sign-off

- [ ] The Rename Expert workspace name is short enough to scan
- [ ] Only files you own sit on the file names
- [ ] A second operator can read the preview handoff
- [ ] The last Rename Expert preview list still opens after a restart
- [ ] Finished names are off the live Rename Expert set
- [ ] The Rename Expert summary still matches the batch rules on the board

## Field Note

Rename Expert is easier to trust when the rename desk stays smaller than the one-click-guess pile it came from. Name the preview list, keep the live names, finish one visible batch-rule pass, and write what changed.

The same loop fits a review, a close-out, or a shared PC. Open the last Rename Expert desk and continue. Do not run batch rules on files you do not own.

A named preview list is enough. Do not pin every name you keep onto the live rename desk.
